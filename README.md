# NBFC-Loan-project
FinEase loan portfolio risk &amp; Excel analytics across 80,000 loans (₹1,492.80 Cr disbursed) and 53 branches in Gujarat &amp; Maharashtra. Tracks ₹557.74 Cr active balance (Sep 2026), 15.50% weighted avg rate, 9.16% Gross NPA (₹51.10 Cr across 3,576 loans), 53.52% collection efficiency, DPD buckets, roll rates, and interactive KPI dashboards.
